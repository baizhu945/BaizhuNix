## Code Habits & Patterns

### File Organization
- Each module has its own .nix file in either `/etc/nixos` or `~/.config/home-manager`
- Modular structure using `imports = [ ... ]` to include other modules
- Skills are organized in `~/.config/home-manager/opencode/skills/` with `default.nix` files

### Code Style
- Uses `let` bindings for reusable values
- Clean indentation (2 spaces)
- Comments in Chinese
- Search https://search.nixos.org/options?channel=unstable before editing nix files

### Common Patterns
- **Modular Design**: Each configuration file focuses on a specific aspect
- **Reusability**: `let` bindings for shared values
- **Extensibility**: Clean imports system for modular configuration
- **Documentation**: Comments in Chinese
- **Consistency**: Standardized patterns for enabling programs, services, and packages
- **Security**: Explicit permission controls and secure password handling

### Example Code Patterns

#### 1. Program Configuration
```nix
programs.ghostty = {
  enable = true;
  enableZshIntegration = true;
  settings = {
    font-family = "Noto Sans Mono CJK HK";
    font-size = "12.0";
  };
};
```

#### 2. Service Configuration
```nix
services.pipewire = {
  enable = true;
  alsa.enable = true;
  pulse.enable = true;
};
```

#### 3. Package Management
```nix
environment.systemPackages = [
  pkgs.git
  pkgs.gh
  pkgs.vscode
];
```

#### 4. File Management
```nix
home.file.".config/ghostty/shaders/cursor_tail.glsl".source = ./ghostty-cursor_tail.glsl;
```

#### 5. Modular Imports
```nix
imports = [
  ./piper.nix
  ./ghostty/ghostty.nix
  ./waybar/waybar.nix
  ./opencode/opencode.nix
];
```

### Do's and Dont's
- 不要使用任何可能会污染环境的命令，比如用除了 `nix` 之外的其他包管理器安装程序。若要临时安装工具请使用 `conda-shell` 或 `nix-shell`
- 不要更改 `/home/<yourusername>/Documents/BaizhuNix` 文件夹
- 在更改 `/home/<yourusername>/.config/` 中的文件之前，先考虑是否能从 `/home/<yourusername>/.config/home-manager/` 声明式地、可复现地解决
- 要保证自己写的每一份 `nix` 代码都是可复现的
